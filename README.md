# Solodesk

Downloads of Solodesk for macOS, a work and money desk for freelance developers: clients,
tickets, time tracking, invoices and taxes in one app.

**Install:** open the latest [release](../../releases/latest), download `Solodesk-<version>.dmg`,
open it and drag Solodesk to Applications. Later versions install themselves from inside the app
(Settings → Updates & startup).

The app is signed with a Developer ID. This repository only holds the release files.
